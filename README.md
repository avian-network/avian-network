Avian Network develops open-source tools for Avian (AVN), led by the Avian Wallet full-node desktop client for Windows, macOS and Linux.

## Current repositories

| Repository | Purpose |
|---|---|
| [Avian-Wallet](https://github.com/avian-network/Avian-Wallet) | C++ full-node desktop wallet and node software for Avian (AVN). |
| [avian-flightdeck](https://github.com/avian-network/avian-flightdeck) | TypeScript progressive web wallet interface for Avian. |
| [electrumxt](https://github.com/avian-network/electrumxt) | Python ElectrumX server fork with Avian support. |
| [avian-coinflow](https://github.com/avian-network/avian-coinflow) | Self-hosted transaction-flow explorer for an indexed Avian node. |
| [avn-multisig-tools](https://github.com/avian-network/avn-multisig-tools) | Python tools for creating, signing and broadcasting AVN multisig transactions. |
| [app-avian](https://github.com/avian-network/app-avian) | Avian-oriented legacy Ledger application codebase for compatible device development. |
| [avian-network-docs](https://github.com/avian-network/avian-network-docs) | Avian Wallet installation, migration, recovery, security and mining guides. |
